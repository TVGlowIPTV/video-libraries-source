# Sources of libmpv-2.dll (Windows)

`libmpv-2.dll`, SHA-256
`72a09be1c0a13d25d4e2a9938e437a4a059a24e2846d82c56b90383ab6343b0e`, is one
library: mpv and FFmpeg with the libraries below linked into it. Each row is
the source of one of them at the exact commit that was built, as an archive
attached to the release
[`windows-libmpv-66af658d`](https://github.com/TVGlowIPTV/video-libraries-source/releases/tag/windows-libmpv-66af658d).
The archives were made with `git archive` from the tree the DLL was built in.
Every library except zvbi is at the same commit as for `66af658d`, so those
archives are the ones attached to that release; release
`windows-libmpv-72a09be1` carries the same files. zvbi is not in the
`66af658d` DLL: its archive and TVGlow's change to it are attached to
`windows-libmpv-72a09be1`. The FFmpeg configuration in `recipe.patch` also
differs (PGS, closed-caption, teletext, TrueHD and MLP decoders).

Where a row says "Built with changes", the patch file holds the difference
between that commit and what was compiled. For FFmpeg it is the three patches
in this folder; for libplacebo, the Python 3.14 patch in this folder; for zimg,
a one-line change of an include's letter case made by the recipe.

Sub-projects that a library keeps as Git submodules are not inside its
archive. The ones this build uses are rows of their own (for example
graphengine for zimg, libudfread for libbluray, and the headers libplacebo
uses).
